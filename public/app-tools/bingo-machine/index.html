Bingo Machine

ビンゴ数字抽選機

ボタンを押すたびに、まだ出ていない数字を1つ抽選します。景品ビンゴ大会の進行に。

使い方の要点（幹事・司会向け）
  1. 「抽選する」を押すと、まだ出ていない数字が1つ出ます（スペースキーでも抽選）。
  2. 出た数字は下の履歴に記録され、リロードしても残ります。
  3. 読み間違えたときは「1つ取り消す」で直前の抽選をなかったことにできます。
  4. 会場の大画面につないで表示すると盛り上がります（表示中は画面を消しません）。
