Bingo Machine

ビンゴ数字抽選機

ボタンを押すたびに、まだ出ていない数字を1つ抽選します。景品ビンゴ大会の進行に。

使い方の要点（幹事・司会向け）
  1. 開始・終了の数字を入力して「範囲を適用」（クイック選択も可）。
  2. 「抽選する」を押すと、まだ出ていない数字が1つ出ます（スペースキーでも抽選）。
  3. 出た数字は下の履歴に記録され、リロードしても残ります。
  4. 読み間違えたときは「1つ取り消す」で直前の抽選をなかったことにできます。
