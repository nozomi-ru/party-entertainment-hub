Talk Theme

トークテーマガチャ

押すだけで会話ネタが出るガチャ。初対面のアイスブレイクや沈黙対策に。

使い方の要点（幹事・司会向け）
  1. カテゴリを選ぶか、下の欄で自分のネタに差し替えます。
  2. 「テーマを引く」でランダムに1つ表示します（スペースキーでも引けます）。
  3. 同じテーマが2回続けて出ないので、テーブルを回しながら使えます。
  4. テーブルごとに順番に引いて話すと、自然と会話が続きます。
ボタンを押してテーマを引いてください

キーボード: スペース = テーマを引く
