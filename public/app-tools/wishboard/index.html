Wishboard

祝福メッセージボード

ゲストがスマホから短い祝福を送れます。司会は大画面で読み上げ・表示できます。

使い方の要点（幹事・司会向け）
  1. Host でルームを開きます（コードは自動生成されます）。
  2. ゲスト用URLをコピーしてQRやチャットで配ります。
  3. 届いたメッセージは一覧とスポットライトで表示。壁の公開／非公開を切り替えられます。
  4. あとで色紙やプレゼント用に「すべてコピー」できます。
